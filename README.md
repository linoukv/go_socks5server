# SOCKS5 代理服务器

一个高性能、功能丰富的 SOCKS5 代理服务器，支持用户管理、流量配额、速度限制和 Web 管理界面。

## 功能特性

- **完整的 SOCKS5 协议支持**: TCP CONNECT 和 UDP ASSOCIATE 命令
- **用户认证**: 支持密码认证和无认证模式
- **流量配额管理**: 支持每日、每周、每月和自定义周期配额
- **速度限制**: 基于令牌桶算法的用户级别限速
- **Web 管理界面**: 提供用户管理、配置设置和实时监控
- **高性能**: 使用 Go 协程和内存池优化吞吐量
- **持久化存储**: SQLite 数据库保存用户数据和配置
- **游戏UDP转发支持**: 完全支持主流游戏udp数据转发,不掉线、不重连

## 快速开始

### 编译

```bash
git clone https://github.com/linoukv/go_socks5server.git
cd go_socks5server
go build .
```

### 运行

```bash
./socks5.exe
```

默认配置：
- SOCKS5 代理: `0.0.0.0:1080`
- Web 管理界面: `http://localhost:8080`
- 数据库文件: `socks5.db`

### 环境变量

| 变量名 | 说明 | 默认值 |
|--------|------|--------|
| `SOCKS5_DB_PATH` | 数据库文件路径 | `socks5.db` |
| `SOCKS5_WEB_ADDR` | Web 管理界面地址 | `:8080` |

## 配置

### 服务器配置

通过 Web 管理界面可以修改以下配置：

| 配置项 | 说明 | 默认值 |
|--------|------|--------|
| 监听地址 | SOCKS5 服务监听地址 | `0.0.0.0:1080` |
| 最大工作协程数 | 限制并发处理连接数 | `1000` |
| 单 IP 最大连接数 | 防止单个客户端滥用 | `65535` |
| TCP Keepalive 周期 | 死连接检测周期 | `15s` |
| 缓冲区池大小 | 内存缓冲区大小 | `32KB` |

### 用户管理

通过 Web 管理界面可以：

- 添加/删除用户
- 设置用户密码
- 配置流量配额
- 设置速度限制
- 启用/禁用用户

## 性能优化

### 内存池

使用三级缓冲区池减少 GC 压力：

| 级别 | 大小 | 用途 |
|------|------|------|
| 小缓冲区 | 8KB | 控制消息、认证数据 |
| 中缓冲区 | 128KB | 普通 HTTP/TCP 数据传输 |
| 大缓冲区 | 2MB | 文件传输、视频流 |

### 连接管理

- **工作协程池**: 限制最大并发数，默认 1000
- **分片连接管理器**: 32 个分片减少锁竞争
- **单 IP 连接限制**: 防止单个客户端滥用资源

## 安全性

- **bcrypt 密码哈希**: 安全存储用户密码
- **CSRF 令牌**: 防止跨站请求伪造
- **验证码登录**: 防止暴力破解
- **IP 速率限制**: 防止 API 滥用
- **输入验证**: 防止 SQL 注入和 XSS 攻击
